One dad joke, at most 200 characters: Dad brings a ladder to the barbecue because he heard the steaks were high. The program in `main.ts` holds the joke as a setup and a punchline, checks it fits the gate (1–200 characters), and writes it to `/output/entry.txt` — that text is the whole entry.

## Run it

```sh
node main.ts
```
